🏗️ APPLICATION ARCHITECTURE OVERVIEW:

The Wanderlust project follows a traditional MVC (Model-View-Controller) architecture built with Node.js, Express.js,
and MongoDB. Here's how all components work together:

│   • Home route (/) - displays featured listings                                                                  │

│   • Error handling (404 and general errors)                                                                      │

┌───────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ 2. DATA LAYER (models/)                                                                                          │
├───────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                                   │
│ 📄 LISTING MODEL (listing.js):                                                                                   │
│   • Schema: title, description, image{url, filename}, price, location, country, reviews[], createdAt            │
│   • Relationships: Has many reviews (references Review model)                                                    │
│   • Pre-validate hook: Auto-generates Unsplash images if no custom image provided                               │
│   • Post-delete hook: Cascades deletion to associated reviews                                                    │
│                                                                                                                   │
│ 📄 REVIEW MODEL (review.js):                                                                                     │
│   • Schema: body, rating (1-5), author (User reference), createdAt                                              │
│   • Relationships: Belongs to User and Listing                                                                   │
│   • Validation: Required body and rating, rating constrained to 1-5                                             │
│                                                                                                                   │
│ 📄 USER MODEL (user.js):                                                                                         │
│   • Schema: email (unique), plus passport-local-mongoose fields                                                  │
│   • Authentication: Uses passport-local-mongoose plugin for username/password                                    │
│   • Provides: authenticate(), serializeUser(), deserializeUser() methods                                        │
│                                                                                                                   │

🔄 DATA FLOW WALKTHROUGH:

┌───────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ EXAMPLE: User Views All Listings                                                                                 │
├───────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                                   │
│ 1. 🌐 USER REQUEST:                                                                                              │
│    • User clicks "Explore All Listings" or navigates to "/listings"                                            │
│                                                                                                                   │
│ 2. 🛣️ ROUTE HANDLING:                                                                                            │
│    • Express matches GET /listings route in app.js                                                              │
│    • Route handler: app.get('/listings', wrapAsync(async (req, res) => {...}))                                 │
│                                                                                                                   │
│ 3. 🗄️ DATABASE QUERY:                                                                                            │
│    • const listings = await Listing.find({});                                                                   │
│    • Mongoose queries MongoDB for all listing documents                                                         │
│    • Returns array of listing objects                                                                           │
│                                                                                                                   │
│ 4. 🎨 TEMPLATE RENDERING:                                                                                        │
│    • res.render('listings/index', { listings, pageTitle: 'All Listings' });                                   │
│    • EJS processes listings/index.ejs template                                                                  │
│    • Template extends layouts/boilerplate.ejs                                                                   │
│    • Loops through listings array to generate HTML cards                                                        │
│                                                                                                                   │
│ 5. 📤 RESPONSE:                                                                                                  │
│    • Complete HTML page sent back to browser                                                                    │
│    • Browser renders the listing grid with Bootstrap styling                                                    │
│                                                                                                                   │
└───────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ EXAMPLE: User Creates New Listing                                                                                │
├───────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                                   │
│ 1. 🌐 FORM DISPLAY:                                                                                              │
│    • GET /listings/new → renders listings/new.ejs with form                                                     │
│                                                                                                                   │
│ 2. 📝 FORM SUBMISSION:                                                                                           │
│    • User fills form and submits via POST /listings                                                             │
│    • Express body-parser middleware parses form data                                                            │
│                                                                                                                   │
│ 3. ✅ VALIDATION:                                                                                                │
│    • validateListing middleware checks data (can use JOI schemas)                                               │
│    • If invalid, returns error; if valid, proceeds                                                              │
│                                                                                                                   │
│ 4. 💾 DATABASE SAVE:                                                                                             │
│    • const listing = new Listing(req.body);                                                                     │
│    • await listing.save();                                                                                      │
│    • Mongoose creates new document in MongoDB                                                                   │
│    • Pre-validate hook generates Unsplash image if needed                                                       │
│                                                                                                                   │
│ 5. 🔄 REDIRECT:                                                                                                  │
│    • res.redirect(`/listings/${listing._id}`);                                                                  │
│    • User redirected to view their new listing                                                                  │
│                                                                                                                   │

📋 LISTING MANAGEMENT:
   • Create: Form validation, auto-image generation
   • Read: Grid view, individual listing pages
   • Update: Edit forms with pre-populated data
   • Delete: Cascade delete reviews when listing deleted

⭐ REVIEW SYSTEM:
   • Star ratings (1-5)
   • Text reviews
   • Associate reviews with listings and users
   • Display average ratings and review counts

🔍 EXPERIENCES/FILTERING:

🔐 AUTHENTICATION:
   • User registration and login

💬 USER FEEDBACK:
   • Flash messages for success/error notifications
   • Form validation feedback

🎨 UI/UX:
