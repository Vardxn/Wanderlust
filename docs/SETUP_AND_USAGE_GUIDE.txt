🐛 TROUBLESHOOTING:

┌───────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ COMMON ISSUES & SOLUTIONS:                                                                                       │
├───────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                                   │
│ ❌ "npm is not recognized"                                                                                       │
│   • Solution: Install Node.js from https://nodejs.org/                                                         │
│   • Restart VS Code and terminal after installation                                                             │
│                                                                                                                   │
│ ❌ "nodemon is not recognized"                                                                                   │
│   • Solution: Use 'npx nodemon app.js' instead of 'nodemon app.js'                                             │
│   • OR: Install globally with 'npm install -g nodemon'                                                         │
│                                                                                                                   │
│ ❌ "MongooseError: Operation buffering timed out"                                                                │
│   • Solution: MongoDB is not running or connection string is wrong                                              │
│   • Check MongoDB service in Windows Services                                                                   │
│   • Verify connection string in app.js or .env file                                                            │
│                                                                                                                   │
│ ❌ "Cannot find module './models/...' "                                                                          │
│   • Solution: Check if model files exist in models/ folder                                                     │
│   • Make sure file names match exactly (case-sensitive)                                                        │
│                                                                                                                   │
│ ❌ "SyntaxError: Unexpected token"                                                                               │
│   • Solution: Check for typos in JavaScript files                                                              │
│   • Look for missing commas, brackets, or quotes                                                               │
│                                                                                                                   │
│ ❌ "Port 8080 already in use"                                                                                    │
│   • Solution: Stop other servers running on port 8080                                                          │
│   • OR: Change port in app.js (const port = process.env.PORT || 3000;)                                        │
│                                                                                                                   │
│ ❌ "Failed to resolve view"                                                                                      │
│   • Solution: Check if .ejs files exist in views/ folder                                                       │
│   • Verify template paths in routes match actual file structure                                                │
│                                                                                                                   │
└───────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
