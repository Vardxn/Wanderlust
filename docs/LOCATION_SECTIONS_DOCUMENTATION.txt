📌 FEATURE OVERVIEW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

This feature implements Airbnb-style location-based listing sections on the home page, similar to:
- "Popular homes in Pune"
- "Available in South Goa this weekend"

The system automatically:
✅ Groups all listings by their location
✅ Displays the top 5 locations with the most listings
✅ Shows up to 10 properties per location in horizontal scroll
✅ Updates dynamically as new listings are added
✅ Supports filtering by location/country

🎯 HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Data Collection (Backend)
──────────────────────────────────────────────────────────────────────────────────────────────────
When user visits homepage ('/'):

1. Fetch all listings from MongoDB
2. Create empty object: listingsByLocation = {}
3. Loop through each listing:
   - Get location name
   - Add listing to listingsByLocation[location] array
4. Sort locations by number of listings (descending)
5. Take top 5 locations
6. Send to template


STEP 2: Rendering (Frontend)
──────────────────────────────────────────────────────────────────────────────────────────────────
In home.ejs:

1. Display hero section
2. Display featured listings carousel (first 12 listings)
3. Loop through topLocations array:
   For each location:
   - Get first 10 listings from listingsByLocation[location]
   - Include location-section.ejs component
   - Pass title, location, and listings


STEP 3: Component Display
──────────────────────────────────────────────────────────────────────────────────────────────────
In location-section.ejs:

1. Create section header with location name
2. Add "Show all" link pointing to /listings?location=[location]
3. Create horizontal scroll container
4. Loop through listings (max 10):
   - Display property card
   - Show guest favourite badge if applicable
   - Display image, title, rating, description
   - Show price "for 2 nights"
5. Add favorite button functionality


STEP 4: Filtering (Optional)
──────────────────────────────────────────────────────────────────────────────────────────────────
When user clicks "Show all":

1. Navigate to /listings?location=[location]
2. Backend filters listings by location (case-insensitive)
3. Display filtered results in grid view
4. Update page title to "Listings in [Location]"

Current Implementation:
────────────────────────────────────────────────────────────────────────────────────────────────── 
✓ Fetches all listings once
✓ Groups in-memory (fast)
✓ No additional database queries
✓ Efficient for small-medium datasets (< 1000 listings)

For Large Datasets (>1000 listings):
────────────────────────────────────────────────────────────────────────────────────────────────── 
Consider using MongoDB aggregation:

const locationStats = await Listing.aggregate([
    { $group: { _id: '$location', count: { $sum: 1 } } },
    { $sort: { count: -1 } },
    { $limit: 5 }
]);

Then fetch only needed listings per location.
