🎯 PRICE FORMATTING STANDARD
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ CORRECT FORMAT:
   ₹<%= listing.price.toLocaleString() %>

   Examples:
   - listing.price = 5000    → Display: ₹5,000
   - listing.price = 50000   → Display: ₹50,000
   - listing.price = 500000  → Display: ₹5,00,000

❌ INCORRECT FORMAT (DO NOT USE):
   ₹<%= listing.price %>
   
   This displays prices without thousands separators (e.g., ₹50000 instead of ₹50,000)

METHOD: .toLocaleString()
────────────────────────────────────────────────────────────────────────────────────────────────

The JavaScript .toLocaleString() method formats numbers with locale-specific separators.

In Indian locale (default):
  - 1000 → 1,000
  - 10000 → 10,000
  - 100000 → 1,00,000
  - 1000000 → 10,00,000

For calculations involving prices:
  - Simple display: listing.price.toLocaleString()
  - After calculation: (listing.price * 5).toLocaleString()
  - With rounding: Math.round(listing.price * 0.1).toLocaleString()

✅ CONSISTENCY CHECKLIST
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

When adding or modifying price displays, ensure:

☑ Always use .toLocaleString() for number formatting
☑ Use ₹ (Indian Rupee symbol) as currency symbol
☑ Place currency symbol before the amount
☑ Add spacing appropriately (e.g., "₹50,000 night" not "₹50,000night")
☑ Use consistent font-weight for price amounts
☑ Maintain consistent "night" label format within the same component

  - White text
  - Used in home page carousel and city sections

.price-amount

  - Used for emphasizing the price number
